# Security policy

This repository is a pre-implementation planning project, not software suitable for patient care.

Never put patient information, access tokens, private record screenshots or production exports in an issue, pull request or attachment. Use synthetic reproductions.

For a suspected vulnerability, use GitHub private vulnerability reporting under the repository's Security tab when enabled. If unavailable, do not disclose sensitive details in a public issue; request a private reporting channel without including exploit data or patient information.

Before a supported release, maintainers must publish supported versions, response expectations, advisories and upgrade procedures. See [release gates](docs/SECURITY-AND-READINESS.md).
